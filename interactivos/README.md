# Interactivos

Archivos HTML autocontenidos (por ejemplo, simuladores hechos con Claude).

Cada archivo `nombre.html` que subas aquí queda publicado en:
https://carlosdhoyos.github.io/intro_2_hydrology/interactivos/nombre.html

Usa nombres en minúscula, sin espacios ni tildes (p. ej. `balance-hidrico.html`).

Para que se vean como el sitio principal (colores, fuente, modo oscuro), usa la
[guía de estilo](GUIA-ESTILO.md): copia su texto en el chat de Claude donde hagas el HTML.
